# Описание
`docs-ai` - Папка с информацией для работы AI в проекте
`docs-ai/artifact/YYYY-MM-DD-<название_фичи>.md/` - Папка для хранения истории, результатов работы AI
`docs-ai/planning/n-<название_задачи>.md` - Папка для хранения задач в формате Markdown, каждая задача описана в свободном формате, имеет свой номер
