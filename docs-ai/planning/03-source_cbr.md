# Проблема
- После задачи 02 курсы берутся только из ЕЦБ (`EcbRateSource`, база EUR, 29 валют)
- ЕЦБ не публикует RUB (приостановлен с 2022-03-01), BGN и HRK. RUB и русская локаль по умолчанию сейчас недоступны: база откатывается на EUR

# Решение
- Добавить второй источник: Банк России (ЦБ РФ), база RUB, около 55 валют
- Источник реализуется за уже существующим контрактом `CurrencyRateSource` (`id`, `baseCode`, `refreshInterval`, `fetch()`), без изменения Domain-интерфейсов
- Изучить контракт источника перед реализацией (не проверялось, ниже только предположения):
  - предположительно `https://www.cbr.ru/scripts/XML_daily.asp`, XML в windows-1251
  - у ЦБ РФ курс задан как «Value за Nominal единиц валюты в рублях» (есть поле `Nominal`, десятичный разделитель — запятая), поэтому курс к базе RUB считается как `Nominal / Value`
  - выяснить расписание обновления (курсы на следующий день публикуются вечером), условия использования, нужны ли `User-Agent` и т.п.
  - проверить доступность ресурса с эмулятора (TLS-цепочка: на эмуляторе с API 34 уже была проблема с корнем Sectigo E46 у ЕЦБ, см. `docs-ai/artifact/2026-10-06-source-data.md`)
