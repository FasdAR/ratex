# Проблема
- ExchangeRateApi - перестал работать с актуальным ключем поскольку тот протух
- ExchangeRateApi - содержит в себе довольно ограниченный список валют

# Решение
- Необходимо выделить несколько источников которые дают бесплатный доступ к курсам валют
- Требование к источнику, это должна быть не обертка над реальными источниками, а низкосортный источник по типу ЦБ-РФ
- Подобрать 1-3 источника к примеру 1 из России 1 из Европы и 1 из США
- Изучить контракты источников, и на основе этого сделать общий контракт взаимодействия к которому в будующем можно будет подключить любой другой источник
- Сделать реализацию пока с одним источником, другие подходящие источники добавить в TODO артифакта

# Итог
- Найти подходящии источники
- Сделать реализацию с одним из них
- Схема реализации такая что на уровне Data ведется работа с условиями источника и его требованиями, например обновление раз в n часов
- На уровне Domain объявлен общий контракт который покрывает почти любые источники уровня Data

# Требования
- Изменения делать в отдельной ветке
