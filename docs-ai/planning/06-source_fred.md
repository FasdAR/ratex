# Проблема
- Источник `fed` (задача 04) берёт курсы H.10 из Data Download Program (DDP) ФРС. На странице релиза H.10 (`https://www.federalreserve.gov/releases/h10/`) написано: «During the week of November 9, the "Build Your Package" feature in the Data Download Program (DDP) will be removed in preparation for the eventual retirement of the DDP», рядом рекомендация переходить на FRED (`https://fred.stlouisfed.org/collection/federal-reserve-board-data`)
- Дата полного отключения DDP не названа. Наш запрос использует готовые пакеты (`type=package`), а не «Build Your Package»: заденет ли их отключение, неизвестно. Страница выбора пакетов (`Choose.aspx?rel=H10`) о выводе из эксплуатации не сообщает
- Хэш пакета в URL (`series=60f32914ab61dfab590e0e470153e3ae`) может смениться. Если `fed` перестанет работать, пропадут курсы ФРС, остальные источники продолжат (дедлайн 5 с), но об отказе никто не узнает

# Решение
- Добавить FRED как запасной канал для H.10: тот же `FedRateSource`, который при ошибке DDP берёт данные из FRED, либо отдельный источник. Выбор в начале задачи (см. открытые вопросы)
- Рабочая гипотеза: `https://fred.stlouisfed.org/graph/fredgraph.csv?id=DEXUSEU,DEXUSUK,...&cosd=<дата>`, ключ не нужен, несколько серий в одном запросе. Это ссылка выгрузки графика, а не документированный API, стабильность не гарантирована
- Альтернатива: официальный API `api.stlouisfed.org/fred/series/observations` с бесплатным ключом. По памяти (не проверялось): одна серия на запрос, лимит около 120 запросов в минуту. Ключ в APK не секрет (его можно извлечь), нужны `BuildConfig`/`local.properties` и ~23 запроса за обновление
- Что уже проверено вживую (2026-10-06, `docs-ai/planning/04-source_usa.md`): `fredgraph.csv?id=DEXUSEU` → `200 application/csv`, формат `дата,значение`; `id=DEXUSEU,DEXUSUK,DEXJPUS,DEXCHUS,DEXCAUS,DEXSZUS` → 200, заголовок `observation_date,<серии>`, история с 1971 года (691 КБ на 6 серий без `cosd`), пропуски — пустые ячейки, последняя точка 2026-10-02; TLS-цепочка FRED: DigiCert Global G3 → DigiCert Global Root G3 (риск низкий)
- Направление котировки у серий FRED разное: `DEXUSEU`, `DEXUSUK` (а также AUD, NZD) — USD за единицу, остальные — единиц за USD. Коды серий для всех 23 валют H.10 даны только по памяти, их нужно сверить (в команде выше проверены 6)

# Открытые вопросы (решить в брейнсторме)
- Запасной канал внутри `FedRateSource` (DDP, при ошибке FRED) или отдельный источник `fred` в `RateSourcePriority`: как это сочетается с кэшем по `sourceId` и с слиянием (оба дают те же курсы, дублировать их в снимке не нужно)
- Какой вариант FRED: `fredgraph.csv` без ключа или официальный API с ключом (критерий: ключ в APK, число запросов, документированность)
- Что считать отказом DDP: любая ошибка запроса, пустой/нераспознанный ответ, `Content-Type` не CSV (при смене хэша DDP, судя по первому опыту, отдавал `200 text/html` с пустым телом)
- Дата снимка: курсы FRED публикуются с тем же лагом (до недели), как и DDP
- Для подмены дат/значений в тестах: нужны фикстуры из настоящего ответа FRED (с `cosd`, чтобы не тянуть историю с 1971 года)
- Проверить на эмуляторе API 34 TLS хоста `fred.stlouisfed.org` (DigiCert, риск низкий)
