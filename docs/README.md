# Описание
`docs` - Папка с документами проекта
`docs/tasks/` - Папка для рабочих задач
`docs/tasks/<number-task>_<name-task>` - Папка для одной определенной задачи
`docs/tasks/<number-task>_<name-task>/TS.md` - Файл описываюший постановку задачи - Перезапись файла, ведется только под заголовком `## Перезапись`, куда вносится информация об изменениях ТЗ или спецификации
`docs/tasks/<number-task>_<name-task>/artifact-ai` - Файл сгенерированные AI для работы над задачей, Файлы в этой папке не поддаются перезаписи
`docs/tasks/<number-task>_<name-task>/artifact-ai/superpowers` - Результаты работы superpowers, Перезапись и запись в этой папке разрешена только superpowers
