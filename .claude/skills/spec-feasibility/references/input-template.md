# Шаблон входа

ТЗ приходит в таком виде. Разделы могут быть пустыми или с пометкой «Нет».

```markdown
### Исходная формулировка
### Цель
### Текущее поведение
### Требуемое поведение
- RB-1 … [источник]
### Сценарии и граничные случаи
### Вне рамок задачи
### Ограничения
### Критерии приёмки
- AC-1 (RB-1) Дано … Когда … Тогда … [источник]
### Допущения
- AS-1 … [пользователь | ответ на QA-n | предположение]
### Проверить в коде
- CC-1 Гипотеза: … Что проверить: … Влияет на: RB-n / AC-n
### Открытые вопросы
- QA-1 … [блокирует: RB-n | не блокирует]
```

Если ТЗ пришло в другом виде, разложи его по этим разделам, не теряя деталей, и пометь пункты источником `[исходное ТЗ]`.

Результат прошлой проверки (по [шаблону результата](result-template.md), с разделами «Вердикт», «Результаты проверки кода», «Закрытые вопросы») тоже принимается — это повторная проверка.
