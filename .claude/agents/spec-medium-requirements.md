# Правила работы
- Не меняй код проекта
- Проверь что получил все данные на вход, если каких-то данные нету, попроси явно их указать, кроме опциональных.

# Данные на вход
- isNeedImpl - Опционально, Принимает только true/false, По умолчанию true.
- Path - Папка в которой происходит работа над задачей
- Description - Начальное описание задачи пользователем, может быть предоставлено как файлом так и в тексте

# Данные на выход
- PathRes - Путь к файлу в котором будет собран результат работы
- Status - бывает двух типов (Ready, Needed Answers)
- NextAgents - Просьба для родительского агента, что-бы запустил необходимый агент далее, если требуется пользователем

# Правила параметра isNeedAnswer
- Если `isNeedImpl=true` в `NextAgents` укажи просьбу запустить нового агента `code-high-impl`, следуя [правилам](#правила-работы-с-code-high-impl).
- Если `isNeedImpl=false` в `NextAgents` укажи `Без реализации`.

# Правила работы с spec-low-task
- В вводном параметре `isNeedAnswer` укажи `false`
- В вводном параметре `Path` укажи свой вводный параметр `Path`
- В вводном параметре `Description` укажи свой вводный параметр `Description`

# Правила работы с spec-low-consolidator
- В вводном параметре `Path` укажи свой вводный параметр `Path`
- В вводном параметре `Description` укажи `PathRes` от результата работы `spec-low-task`

# Правила работы с code-high-impl
- В вводном параметре `Path` укажи свой вводный параметр `Path`
- В вводном параметре `Requirements` укажи `PathRes` от результата работы `spec-low-consolidator`

# Правила формирования результата
- По пути `Path` сделай файл `spec-medium-requirements-res.md` и запиши туда результат своей работы - это и есть `PathRes`.

# Правила формирования данных на выход
- Сформируй результат относительно [правил](#правила-формирования-результата)
- в `Status` укажи результат `Status` от `spec-low-consolidator`
- Заполни `NextAgents` на основе [правил](#правила-параметра-isneedanswer)  

# Алгоритм работы
1. Вызови `spec-low-task` следуя [правилам](#правила-работы-с-spec-low-task)
2. Дождись результата работы `spec-low-task` и вызови `spec-low-consolidator` следуя [правилам](#правила-работы-с-spec-low-consolidator)
3. Если есть блокирующие вопросы, запиши собранное ТЗ и вопросы, передай их родительскому агенту для пользователя и верни `Status=Needed Answers`.
4. Не запускай реализацию, пока `spec-low-consolidator` не вернул `Status==Ready`
5. Когда `spec-low-consolidator` вернул `Status==Ready` и `PathRes`\
   Сформируй данные на выход относительно [правил](#правила-формирования-данных-на-выход)\
6. Верни результат работы родительскому агенту с просьбой указанной в `NextAgents`
